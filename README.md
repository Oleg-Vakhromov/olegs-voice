# olegs-voice

A Claude Code skill that rewrites or drafts business prose (messages, emails, memos, comments, reports, papers, articles) so it reads like a specific person wrote it, not an AI assistant. It combines observed writing habits with William Zinsser's *On Writing Well*; where the two conflict, Zinsser wins.

## Install

Clone into your skills folder:

```
git clone https://github.com/Oleg-Vakhromov/olegs-voice ~/.claude/skills/olegs-voice
```

Or into a project: `.claude/skills/olegs-voice`.

## Layout

- `SKILL.md` – the skill: one voice for every length and genre, human structure, Zinsser's rules, the anti-AI layer, process and checklist
- `references/zinsser.md` – clarity, simplicity, brevity, humanity, with word lists and examples
- `references/composition.md` – how facts sit on the page: openings, order, attribution, endings
- `references/edit_pass.md` – the in-place structure edit after drafting
